# FluxPlayer 纯音频播放

## 模式选择

Demuxer 没有可播放视频流但存在音频流时，Player 设置 `audioOnly_`。该模式支持 FFmpeg 能解码的 MP3、FLAC、WAV、AAC、OGG 等输入，不建立视频解码器、视频 packet 队列或视频 frame 队列。

音频解码与设备输出沿用普通播放管线；初始化或运行中无法输出音频时报告错误，不以空转播放代替声音输出。

## 封面显示

`Player::loadCoverImage()` 遍历带 `AV_DISPOSITION_ATTACHED_PIC` 的流，从 `attached_pic` 解码封面为 RGBA；没有可用内嵌封面时读取内置 `pic2.png`。

窗口使用 480×480 的初始画面尺寸。封面上传 GLRenderer 后通过缓存纹理重绘，主循环不从视频队列取帧；RGBA 显示不经过 YUV 色彩转换。

## 时钟与控制

纯音频使用音频主时钟。S16 采样按倍速和跨回调相位生成输出，成功提交后登记有效媒体覆盖，AVSync 根据排队延迟估算播放位置。欠载补静音不推进媒体时间；有效覆盖耗尽后冻结。

Pause/Resume 保留 PCM 和覆盖锚点；Seek 确认设备清缓存后发布新目标。Demuxer 无视频基准流时使用音频流 time_base 定位，解码对齐与设备恢复沿用普通 Seek 门控。

音量、静音、速度、循环和录音通过 Player 控制命令处理，进度读取音频主时钟，不依赖最后渲染的视频 PTS。音视频时钟偏差的画面位置回退仅用于存在视频播放分支的媒体，纯音频不参与该比较；相对 Seek 也使用实际音频进度。EOF 判断依据启用的音频分支，不等待不存在的视频解码器。

## 源码位置

- `src/core/Player.cpp`：模式选择、封面加载、窗口与主循环。
- `src/decoder/Demuxer.cpp`：音频流选择与定位。
- `src/core/DecodeWorker.cpp`、`src/decoder/AudioDecoder.cpp`：音频解码与 S16 转换。
- `src/audio/AudioOutput.cpp`、`src/core/AVSync.cpp`：设备输出和覆盖时钟。
- `src/renderer/GLRenderer.cpp`：静态 RGBA 与缓存纹理显示。
