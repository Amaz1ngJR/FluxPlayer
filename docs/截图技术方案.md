# FluxPlayer 截图与图片查看

## 1. 截图入口

播放时按 `P` 触发截图。Player 通过 `FrameQueue::peekLastRef()` 获取最后显示帧的独立引用，再根据配置调用 Screenshot；该引用保护数据不被队列 flush 释放，保存操作在调用线程同步执行。

`Screenshot::saveFrame()` 返回保存路径，失败返回空字符串。配置项 `screenshotDir` 和 `screenshotFormat` 由设置界面及 `fluxplayer.ini.sample` 定义；支持 png、jpg、yuv、nv12。

## 2. 编码与原始采样保存

- PNG：使用 swscale 转为 RGB24，再由 FFmpeg PNG 编码器编码。
- JPEG：转换为 JPEG 编码器所需像素格式，再由 MJPEG 编码器编码。
- YUV：`saveFrameYUV()` 保存 I420 的 Y、U、V 平面。
- NV12：保存 Y 平面和交错 UV 平面。

原始格式与源帧不匹配时使用 swscale 转换。写入按有效行宽处理，避免把 linesize 对齐填充当作像素。YUV/NV12 同时生成 `.txt` 元数据，包含宽高、格式及 FFplay 查看命令。

文件名包含时间戳，输出目录按需创建。硬件 AVFrame 不作为 CPU 平面读取：截图路径检查并拒绝硬件帧、记录警告；当前没有从最终 GPU 纹理读取像素的截图路径。

## 3. 图片查看

`Player::open()` 识别图片后调用 `openImageFile()`：

- JPG/PNG 等压缩图片通过 FFmpeg 解码为单帧，必要时转换为渲染器使用的像素格式。
- YUV/NV12 读取原始采样，按元数据或文件大小匹配尺寸；匹配失败使用代码中的默认尺寸并记录警告。
- 图片作为私有 Frame 提交到视频 FrameQueue，通过同一渲染器显示；不启动普通音视频播放 Worker。
- 图片模式保留窗口、缩放和缓存纹理重绘，UI 按图片模式隐藏不适用的播放控制。

原始 YUV 文件不自带分辨率，错误的尺寸解释会造成画面异常，元数据与文件内容必须对应。

## 4. 截图反馈

Player 在保存成功后通知界面。截图反馈使用渲染器缓存纹理和 UI 动画状态，不建立独立的视频解码链。同步保存会占用触发线程，因此不属于后台异步编码。

## 5. 查看原始文件

以下命令仅用于查看已经生成的原始采样，尺寸替换为元数据中的值：

```bash
ffplay -f rawvideo -pixel_format yuv420p -video_size 1920x1080 screenshot.yuv
ffplay -f rawvideo -pixel_format nv12 -video_size 1920x1080 screenshot.nv12
```

## 6. 源码位置

- `include/FluxPlayer/utils/Screenshot.h`、`src/utils/Screenshot.cpp`
- `src/core/Player.cpp`：快捷键、帧引用和图片打开。
- `src/ui/Controller.cpp`、`src/ui/SettingsSchema.cpp`：反馈与配置。
- `src/renderer/GLRenderer.cpp`：图片与缓存纹理绘制。
