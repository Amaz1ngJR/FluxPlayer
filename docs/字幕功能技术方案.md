# FluxPlayer 内嵌字幕

## 支持范围

播放器解码媒体中的文本字幕流，包括 SRT、ASS/SSA、WebVTT 和 mov_text。Demuxer 选择第一条字幕流，SubtitleDecoder 调用 FFmpeg 字幕解码接口，SubtitleManager 按播放时间提供文本，UI 的字幕 Surface 负责绘制。

当前不加载外挂字幕，不切换多个字幕轨，不生成 ASR 字幕。PGS/DVB 等位图字幕在解码结果遍历时跳过并记录调试日志，不上传为纹理。ASS 样式作为控制标签清理，不执行完整 ASS 排版。

## 数据流与线程

```text
DemuxWorker 识别字幕包
  → SubtitleDecoder::decode()
  → 按当前输入身份发布字幕条目
  → SubtitleManager::addEntry()
  → UI 按播放时间查询 getCurrentText()
  → Lua subtitle Surface
```

SubtitleManager 使用互斥锁保护条目。Seek 和输入替换清理旧字幕，避免上一时间线的文本继续显示。

## 时间与文本处理

`SubtitleDecoder::decode()` 优先使用 packet PTS，没有 PTS 时使用 DTS。显示时长优先使用 `end_display_time`，其次使用 packet duration，两者均不可用时采用 5 秒。

解码结果中的 ASS/TEXT 内容经过 `stripASSOverrides()`：提取 ASS 文本字段，移除 `{…}` 控制标签，将 `\N`、`\n` 转为换行、`\h` 转为空格，清理尾部空白并限制文本长度。FFmpeg 的 `AVSubtitle` 通过作用域守卫释放，失败路径也释放解码结果。

SubtitleManager 按起始 PTS 排序；顺序到达时尾插，相同的队尾文本与时间被去重，乱序条目按位置插入。条目数量超过容量时裁剪旧记录，查询时清理已过期条目，返回当前时间命中的第一条文本。

## 配置与显示

`subtitleEnabled` 控制显示开关，`subtitleFontScale` 控制字号缩放；具体配置见 `fluxplayer.ini.sample`。皮肤的 subtitle Surface 使用运行时提供的字幕文本，文本布局和颜色由皮肤定义。

## 源码位置

- `src/decoder/Demuxer.cpp`：字幕流选择。
- `src/core/DemuxWorker.cpp`：字幕包路由与输入身份边界。
- `src/subtitle/SubtitleDecoder.cpp`：FFmpeg 解码与文本清理。
- `src/subtitle/SubtitleManager.cpp`：时间索引、排序与清理。
- `src/ui/Controller.cpp`、`source/UI/skins/`：字幕数据与绘制。
