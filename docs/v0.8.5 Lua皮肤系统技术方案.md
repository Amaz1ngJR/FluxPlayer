# v0.8.5 Lua 皮肤系统技术方案

## 1. 目标与动机

### 1.1 现状分析

FluxPlayer v0.8.4 采用 JSON 静态配置的皮肤系统：

- **数据驱动**：`skin.json` 描述颜色、度量、字体等静态参数
- **结构完整**：支持 roles（语义颜色）、metrics（尺寸）、surfaces（界面布局参数）、decoration（装饰开关）
- **热重载**：支持 mtime 轮询 + debounce，修改 JSON 后秒级生效
- **三层搜索**：User / Dev / BuiltIn 目录优先级回退

**局限性**：

1. **静态配置**：JSON 只能描述数据，无法表达逻辑（条件、循环、动画）
2. **布局硬编码**：HomeScreen / PlayerController / SettingsPanel 等界面布局写死在 C++ 代码中
3. **扩展性差**：新增 UI 元素需要修改 C++、重新编译
4. **自定义受限**：用户只能调整颜色/尺寸参数，无法改变布局结构

### 1.2 v0.8.5 目标

将皮肤系统从**静态配置**升级到**可编程脚本**，实现：

- ✅ **动态布局**：用 Lua 脚本描述 UI 结构，支持条件渲染、响应式布局
- ✅ **实时调整**：修改 Lua 脚本后秒级生效，设计师快速迭代
- ✅ **逻辑表达**：支持动画、状态机、事件响应等 JSON 无法描述的场景
- ✅ **向后兼容**：现有 JSON 皮肤继续工作，Lua 完全可选
- ✅ **安全隔离**：沙箱执行，禁止文件 IO / 网络访问 / 系统调用

**非目标**：

- ❌ 不支持完全重写渲染器（仍基于 ImGui）
- ❌ 不支持修改 C++ 核心逻辑（解码、同步、命令队列）
- ❌ 不支持第三方网络加载皮肤（安全考虑）

#### A. FluxUI Widget System

**职责**：提供声明式 UI 组件抽象

```cpp
// include/FluxPlayer/ui/FluxUI/Widget.h
namespace FluxUI {

/// 基类：所有 UI 元素
class Widget {
public:
    virtual ~Widget() = default;
    
    /// 计算理想尺寸（不考虑父容器约束）
    virtual ImVec2 measureContent() = 0;
    
    /// 在指定区域内布局并渲染
    virtual void render(const Rect& bounds) = 0;
    
    /// 事件处理（返回 true 表示已消费事件）
    virtual bool handleEvent(const Event& event) { return false; }
    
    /// 样式属性
    struct Style {
        std::optional<float> width;   // 固定宽度，nullopt 表示自适应
        std::optional<float> height;
        Padding padding = {0, 0, 0, 0};
        Alignment align = Alignment::TopLeft;
        std::string theme = "default";  // primary / secondary / muted
    } style;
    
protected:
    const SkinSnapshot* skin_ = nullptr;
};

/// 按钮组件
class Button : public Widget {
public:
    explicit Button(const std::string& text);
    
    ImVec2 measureContent() override;
    void render(const Rect& bounds) override;
    
    std::function<void()> onClick;
    
private:
    std::string text_;
    bool hovered_ = false;
    bool pressed_ = false;
};

/// 容器组件（支持自动布局）
class Container : public Widget {
public:
    void addChild(std::unique_ptr<Widget> child);
    
    ImVec2 measureContent() override;
    void render(const Rect& bounds) override;
    
    enum class LayoutMode { VBox, HBox, Flexbox };
    LayoutMode layout = LayoutMode::VBox;
    float gap = 0.0f;  // 子元素间距
    
private:
    std::vector<std::unique_ptr<Widget>> children_;
    std::vector<Rect> computeLayout(const Rect& bounds);
};

} // namespace FluxUI
```

#### B. Layout Engine

**职责**：自动计算子元素位置和尺寸

```cpp
// src/ui/FluxUI/Layout.cpp
std::vector<Rect> Container::computeLayout(const Rect& bounds) {
    std::vector<Rect> result;
    
    if (layout == LayoutMode::VBox) {
        // 垂直布局
        float y = bounds.min.y + style.padding.top;
        
        for (auto& child : children_) {
            auto contentSize = child->measureContent();
            
            // 应用子元素的 width 约束
            float w = child->style.width.value_or(
                bounds.width() - style.padding.left - style.padding.right
            );
            float h = child->style.height.value_or(contentSize.y);
            
            // 水平对齐
            float x = bounds.min.x + style.padding.left;
            if (child->style.align == Alignment::Center) {
                x = bounds.center().x - w / 2;
            } else if (child->style.align == Alignment::Right) {
                x = bounds.max.x - style.padding.right - w;
            }
            
            result.push_back(Rect{ImVec2(x, y), ImVec2(x + w, y + h)});
            y += h + gap;
        }
        
    } else if (layout == LayoutMode::HBox) {
        // 水平布局（类似实现）
        // ...
    }
    
    return result;
}
```

**布局模式**：

- **VBox**：垂直堆叠，自上而下
- **HBox**：水平排列，自左而右
- **Flexbox**（Phase 3）：CSS Flexbox 风格，支持 flex-grow / flex-shrink / justify-content

#### C. Theme System

**职责**：将语义化主题名称映射到 SkinSnapshot 颜色

// src/ui/FluxUI/Theme.cpp
SkinColor Widget::getThemeColor(const std::string& theme, const std::string& state) {
    // 语义化主题映射
    if (theme == "primary") {
        if (state == "hover") return skin_->colors.accentPrimarySoft;
        if (state == "active") return skin_->colors.accentSecondary;
        return skin_->colors.accentPrimary;
        
    } else if (theme == "secondary") {
        return skin_->colors.accentSecondary;
        
    } else if (theme == "danger") {
        return skin_->colors.stateError;
        
    } else if (theme == "success") {
        return skin_->colors.stateSuccess;
        
    } else if (theme == "muted") {
        return skin_->colors.textMuted;
    }
    
    // 默认
    return skin_->colors.bgPanel;
}

void Widget::applyDecorations(ImDrawList* dl, const Rect& bounds) {
    // 自动应用皮肤装饰
    if (skin_->decoration.glow) {
        DrawGlowRect(dl, bounds.min, bounds.max, 
                     getThemeColor(style.theme, "normal"), *skin_, 
                     skin_->metrics.radius.button, 3);
    }
    
    if (skin_->decoration.cutCorners) {
        DrawCornerCuts(dl, bounds.min, bounds.max,
                       skin_->colors.linePrimary, *skin_, 12.0f, 1.5f);
    }
}

#### D. LuaSkinRuntime

**职责**：管理 Lua 虚拟机、API 绑定、沙箱策略

```cpp
// include/FluxPlayer/ui/LuaSkinRuntime.h
class LuaSkinRuntime {
public:
    /// 初始化虚拟机，绑定 FluxUI API
    bool initialize(const fs::path& skinDir);
    
    /// 执行布局脚本，返回根 Widget
    Widget* getRootWidget(const std::string& surfaceName);
    
    /// 热重载所有 Lua 脚本
    void reloadScripts();
    
    /// 事件分发（按钮点击等）
    void dispatchEvent(const std::string& eventName, const LuaValue& payload);
    
    /// 更新动画系统（每帧调用）
    void update(float deltaTime);
    
private:
    lua_State* L_ = nullptr;
    fs::path skinDir_;
    std::map<std::string, int64_t> scriptMtimes_;  // 热重载监听
    std::unique_ptr<Widget> cachedRootWidget_;     // Widget 树缓存
    uint64_t lastStateHash_ = 0;                   // Lua 状态哈希
    
    void setupSandbox();      // 禁用 io / os / debug 库
    void bindFluxUIAPI();     // 暴露 ui.* 命名空间
    void bindSkinAPI();       // 暴露 skin.* 访问 SkinSnapshot
    void bindEventAPI();      // 暴露 events.* 事件系统
};
```

**沙箱策略**：

```cpp
void LuaSkinRuntime::setupSandbox() {
    // 移除危险库
    lua_pushnil(L_);
    lua_setglobal(L_, "io");       // 禁止文件 IO
    lua_pushnil(L_);
    lua_setglobal(L_, "os");       // 禁止系统调用
    lua_pushnil(L_);
    lua_setglobal(L_, "debug");    // 禁止调试钩子
    
    // 限制 require 路径（只能加载 skinDir 内的脚本）
    lua_getglobal(L_, "package");
    lua_pushstring(L_, (skinDir_ / "?.lua").string().c_str());
    lua_setfield(L_, -2, "path");
    lua_pop(L_, 1);
    
    // 设置指令计数限制（防止死循环）
    lua_sethook(L_, instructionCountHook, LUA_MASKCOUNT, 100000);
    
    // 内存配额（防止内存炸弹）
    lua_setallocf(L_, limitedAllocator, (void*)&memoryQuota);
}
```

class SkinManager {
public:
    bool initialize(const std::string& selectedId, bool hotReload);
    
    /// 检查皮肤是否包含 Lua 脚本
    bool hasLuaScript(const std::string& surfaceName) const;

    LuaSkinRuntime* getLuaRuntime() { return luaRuntime_.get(); }
    
private:
    std::unique_ptr<LuaSkinRuntime> luaRuntime_;  // 新增
};

// src/ui/SkinManager.cpp
bool SkinManager::initialize(const std::string& selectedId, bool hotReload) {
    // ... 现有 JSON 加载逻辑 ...
    
    // 检查是否存在 skin.lua
    fs::path luaPath = activeDir_ / "skin.lua";
    if (fs::exists(luaPath)) {
        luaRuntime_ = std::make_unique<LuaSkinRuntime>();
        if (!luaRuntime_->initialize(activeDir_)) {
            LOG_ERROR("Failed to load Lua skin: " + selectedId);
            luaRuntime_.reset();  // 回退到 JSON-only 模式
        } else {
            LOG_INFO("Lua skin enabled: " + selectedId);
        }
    }
    
    return true;
}

bool SkinManager::hasLuaScript(const std::string& surfaceName) const {
    return luaRuntime_ && luaRuntime_->hasLayout(surfaceName);
}

Widget* SkinManager::renderLuaSurface(const std::string& surfaceName) {
    if (!luaRuntime_) return nullptr;
    return luaRuntime_->getRootWidget(surfaceName);
}

## 6. 性能优化

### 6.1 布局缓存

```cpp
class Widget {
    struct LayoutCache {
        ImVec2 lastParentSize;
        std::vector<Rect> cachedBounds;
        uint64_t skinGeneration;
    };
    mutable LayoutCache cache_;
    
    void render(const Rect& bounds) {
        auto skin = SkinManager::instance().current();
        
        // 窗口尺寸和皮肤未变 → 复用上次布局
        if (cache_.lastParentSize == bounds.size() &&
            cache_.skinGeneration == skin->generation) {
            renderCached(cache_.cachedBounds);
            return;
        }
        
        // 重新计算布局
        cache_.cachedBounds = computeLayout(bounds);
        cache_.lastParentSize = bounds.size();
        cache_.skinGeneration = skin->generation;
        
        renderCached(cache_.cachedBounds);
    }
};
```

### 6.2 惰性更新

```cpp
Widget* LuaSkinRuntime::getRootWidget(const std::string& surfaceName) {
    // 计算 Lua 状态哈希（state 表的内容）
    uint64_t currentHash = computeStateHash();
    
    if (currentHash == lastStateHash_ && cachedRootWidget_) {
        return cachedRootWidget_.get();  // 复用上次构建的 Widget 树
    }
    
    // 执行 Lua 重新构建
    lua_getglobal(L_, surfaceName.c_str());
    lua_getfield(L_, -1, "render");
    lua_pcall(L_, 0, 1, 0);
    cachedRootWidget_ = parseWidget(L_, -1);
    
    lastStateHash_ = currentHash;
    return cachedRootWidget_.get();
}
```

### 6.3 性能指标

**目标**：

- 布局计算时间：< 0.5ms per frame（60fps 无影响）
- Lua 执行时间：< 0.3ms（惰性更新，仅状态变化时执行）
- Widget 树构建：< 0.2ms（缓存命中率 > 95%）
- 总开销：< 1ms per frame（比纯 C++/ImGui 慢不超过 2 倍）

## 7. 安全与限制

### 7.1 沙箱策略

| 限制项 | 策略 | 原因 |
|--------|------|------|
| 文件 IO | 禁用 `io` 库 | 防止读取敏感文件 |
| 系统调用 | 禁用 `os` 库 | 防止执行外部程序 |
| 调试钩子 | 禁用 `debug` 库 | 防止修改虚拟机内部状态 |
| 模块加载 | 限制 `require` 路径到 `skinDir` | 防止加载系统库 |
| 指令计数 | 10 万条指令/帧限制 | 防止死循环 |
| 内存配额 | 16 MB 限制 | 防止内存炸弹 |

### 7.2 错误处理

```cpp
Widget* LuaSkinRuntime::getRootWidget(const std::string& surfaceName) {
    lua_getglobal(L_, surfaceName.c_str());
    lua_getfield(L_, -1, "render");
    
    // 使用 lua_pcall 捕获错误
    int status = lua_pcall(L_, 0, 1, 0);
    if (status != LUA_OK) {
        const char* error = lua_tostring(L_, -1);
        LOG_ERROR("Lua render() failed: " + std::string(error));
        
        // 显示错误 overlay（开发者模式）
        if (Config::developerMode) {
            showLuaErrorOverlay(error);
        }
        
        lua_pop(L_, 1);
        return nullptr;  // 触发 C++ fallback
    }
    
    return parseWidget(L_, -1);
}
```

## 9. 风险评估与缓解

### 风险 1: 性能开销

**问题**：每帧执行 Lua 代码可能拖慢渲染（60fps → 30fps）

**缓解**：

- 使用 LuaJIT JIT 编译（减少 90%+ 开销）
- 布局缓存：窗口尺寸不变时复用计算结果
- 惰性更新：只在 Lua 状态变化时重新构建 Widget 树
- 限制 Lua 执行时间（超时中断）
- 性能监控：`if (luaDuration > 16ms) fallback_to_cpp()`

### 风险 2: 脚本安全性

**问题**：恶意 Lua 脚本可能读取文件、执行系统命令

**缓解**：

- 移除 `io` / `os` / `debug` 库
- 限制 `require` 路径（仅皮肤目录内）
- 指令计数限制（防死循环）
- 内存配额（防内存炸弹）
- 资源大小限制（皮肤目录 16 MB 上限）

### 风险 3: 向后兼容性

**问题**：现有 JSON 皮肤在 Lua 模式下失效

**缓解**：

- Lua 完全可选，无 `.lua` 文件时使用现有逻辑
- 提供 `base` 继承机制，Lua 皮肤可继承 JSON 配置
- C++ fallback：Lua 出错自动切回硬编码布局
- 保留现有 C++ UI 代码，与 Lua 共存

### 风险 4: 调试困难

**问题**：Lua 错误堆栈难以定位

**缓解**：

- 集成 `luaL_traceback`，捕获完整调用栈
- 提供 `console.log()` 到 FluxPlayer 日志系统
- 开发者模式：实时显示 Lua 错误 overlay
- 语法检查工具（linter）
