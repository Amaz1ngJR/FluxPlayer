# FluxPlayer 观看历史

## 1. 功能与存储

观看历史记录本地文件、网页视频和直接网络来源，始终开启，没有独立配置开关。`HistoryStore` 将数据保存在应用缓存目录的 `history.json`，与 `fluxplayer.ini` 同级；写入失败不阻断播放。

列表最多保留 10 条，按最近使用顺序展示。同一 path 通过稳定哈希生成 id，重复观看更新已有条目并置顶，超限淘汰队尾。

## 2. 数据字段

`HistoryEntry` 包含：

| 字段 | 含义 |
| --- | --- |
| `id` | path 的稳定哈希，用于去重和删除 |
| `path` | 本地路径或原始网页/网络 URL，作为重播依据 |
| `title` | 显示标题 |
| `sourceType` | LocalFile、WebVideo 或 NetworkUrl |
| `lastPlayedAt` | 最近播放的 Unix 时间戳 |
| `duration` | 媒体时长，0 表示未知或直播 |
| `lastPosition` | 上次退出位置，当前 UI 不用它自动续播 |
| `uploader`、`platform` | 网页来源附加信息 |

网页历史保存原始页面地址，不把临时签名媒体 URL 当作重播依据。

## 3. 接口与并发

HistoryStore 提供 `loadAll()`、`record()`、`updatePosition()`、`remove()` 和 `clear()`。内部 mutex 覆盖一次完整的读取、修改和写入；JSON 细节封装在 `.cpp`，头文件只暴露数据与接口。

文件不存在或解析失败时读取返回空列表。`record()` 执行 upsert 和容量裁剪；`updatePosition()` 只更新已有条目的退出位置；删除不存在的 id 为幂等操作；clear 写入空列表，不删除存储文件。

## 4. UI 与重播

HomeScreen 向 Lua home Surface 提供历史数据，皮肤负责列表外观、布局和交互。点击历史条目使用记录的 path 进入普通打开流程；网页输入重新经过 OpeningScreen 提取，直接网络输入交给正常网络打开路径。

删除和清空动作由 HomeScreen 调用 HistoryStore，并更新界面数据。功能不包含缩略图抓帧、跨设备同步或云端存储。

## 5. 源码位置

- `include/FluxPlayer/utils/HistoryStore.h`、`src/utils/HistoryStore.cpp`
- `src/ui/HomeScreen.cpp`、`source/UI/skins/`
- `src/main.cpp`：播放与历史记录的调用边界。
